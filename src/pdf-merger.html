FAQ

Do my PDFs ever leave my device?
No. All merging happens locally in your browser using pdf-lib and PDF.js — two open-source libraries that run entirely client-side. Your files are never uploaded anywhere.
Can I include only certain pages from each PDF?
Yes. Each file card has an optional Pages field. Leave it empty to include all pages, or type a range like '1-3, 7, 9-' (9- means page 9 through the last page).
What image formats can I drop in alongside PDFs?
PNG, JPEG, and WebP images are accepted. Each image is promoted to a single PDF page, sized to fit A4 (portrait) with the image centered.
What does 'Strip metadata' do?
It clears the Title, Author, Creator, and Producer fields from the output PDF. Useful when you want to share a document without leaking authoring details.
What does 'Add bookmarks per source' do?
It adds a top-level outline entry (bookmark) for each input file, pointing to the first page contributed by that file. This makes it easy to jump between source documents in any PDF viewer.
