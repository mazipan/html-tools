Components, tokens, and patterns shared across the suite. Reach for one of these classes before redefining anything inline.

Internal page. Contributor reference — not linked from the index, sitemap, or cross-tool footer. Tweak any class in src/styles.css and reload to see changes here.

Disclosure (collapsible)

Animated <details> with chevron rotation and content slide. Wrap the body in a .disclosure-content > .disclosure-body pair so the content height animates from 0 → its real auto height (no max-height cap).

What's a disclosure for?
Use it for FAQ entries, cheat sheets, "explain this" panels — anywhere the user might want to reveal extra context but doesn't need it open by default.
Open by default
Add the open attribute to render a section already expanded. Useful for the first FAQ on a page.
Tall content animates correctly

The animation uses grid-template-rows: 0fr → 1fr, which interpolates to the body's true auto-height. No max-height fudge, no cut-off content.

A consequence: the body can be as tall as it needs to be — long FAQ answers, multi-paragraph explainers, even small tables.

Just don't put fixed-height children inside; let the content size itself.

<details class="disclosure">
  <summary>Title</summary>
  <div class="disclosure-content">
    <div class="disclosure-body">
      Body content here.
    </div>
  </div>
</details>

Tooltip

Small hover/focus popup for inline explanations. The trigger is a circled i; the popup floats above and disappears when the user moves on. tabindex="0" on the wrapper makes the keyboard path work via :focus-within.

Error correction i L: ~7% recovery · M: ~15% · Q: ~25% · H: ~30%. Higher levels survive more damage but fit less data. Quiet zone i 4-module light border around the code. Some scanners refuse codes that sit flush against another element.

Reach for it any time a control's label can't tell the whole story on its own — keep the popup under ~240 px wide, one or two sentences, plain language.

<span class="tooltip" tabindex="0">
  <span class="tooltip-trigger" aria-hidden="true">i</span>
  <span class="tooltip-text" role="tooltip">Explanatory text…</span>
</span>

Loader

Inline loading state: a pulsing SVG beacon, text that fades between messages, and three wave-bouncing dots. Show/hide with .hidden; call startLoader(el, msgs) to start cycling and get back a { stop } handle.

Loading

Building PDF 

<!-- HTML -->
<p class="loader hidden" role="status" aria-live="polite">
  <svg class="loader-icon" width="16" height="16"
       viewBox="0 0 16 16" fill="none" aria-hidden="true">
    <circle cx="8" cy="8" r="3" fill="var(--accent)"/>
    <circle cx="8" cy="8" r="3" fill="none" stroke="var(--accent)"
            stroke-width="1.5" class="loader-pulse-ring"/>
  </svg>
  <span class="loader-msg">Loading</span>
  <span class="loader-dots" aria-hidden="true">
    <span></span><span></span><span></span>
  </span>
</p>

<!-- JS helper (copy into your tool) -->
function startLoader(el, msgs, intervalMs = 3000) {
  const msgEl = el.querySelector('.loader-msg');
  if (!msgEl || !msgs.length) return { stop: () => {} };
  msgEl.textContent = msgs[0];
  let i = 0;
  const timer = setInterval(() => {
    msgEl.classList.add('fade');
    setTimeout(() => {
      i = (i + 1) % msgs.length;
      msgEl.textContent = msgs[i];
      msgEl.classList.remove('fade');
    }, 260);
  }, intervalMs);
  return { stop() { clearInterval(timer); msgEl.classList.remove('fade'); } };
}

<!-- Usage -->
const msgs = ['Loading', 'Almost there', 'Just a moment', 'Hang tight'];
loaderEl.classList.remove('hidden');
const loader = startLoader(loaderEl, msgs);

// when done:
loader.stop();
loaderEl.classList.add('hidden');

Stats panel

Multi-row results list shown below the action button when the user has just compressed / converted / processed a batch and the queue cards live too far up the page to scroll back to. One row per file: name · before → after · delta chip. No thumbnails — compact so a 25-row list stays readable. Used by PDF Compressor; reach for it whenever a batch tool's stats are otherwise stranded above the fold.

Five delta variants cover the common outcomes: good (got smaller), bad (got bigger), neutral (≈ unchanged), skipped (no work done), error (failed).
