Switch (toggle)

Pill-shaped on/off switch for a single binary state — typically gating a section of the UI (e.g. "enable gradient", "show preview"). Use a .switch label wrapping a native <input type="checkbox">; keyboard, screen-reader, and form-submit semantics come for free. Prefer a regular checkbox for multi-select option lists.

<label class="switch">
  <input type="checkbox">
  <span>Gradient fill</span>
</label>

Disclosure (collapsible)

Animated <details> with chevron rotation and content slide. Wrap the body in a .disclosure-content > .disclosure-body pair so the content height animates from 0 → its real auto height (no max-height cap).

What's a disclosure for?
Use it for FAQ entries, cheat sheets, "explain this" panels — anywhere the user might want to reveal extra context but doesn't need it open by default.
Open by default
Add the open attribute to render a section already expanded. Useful for the first FAQ on a page.
Tall content animates correctly

The animation uses grid-template-rows: 0fr → 1fr, which interpolates to the body's true auto-height. No max-height fudge, no cut-off content.

A consequence: the body can be as tall as it needs to be — long FAQ answers, multi-paragraph explainers, even small tables.

Just don't put fixed-height children inside; let the content size itself.

<details class="disclosure">
  <summary>Title</summary>
  <div class="disclosure-content">
    <div class="disclosure-body">
      Body content here.
    </div>
  </div>
</details>
