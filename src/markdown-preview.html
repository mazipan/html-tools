FAQ

Which Markdown flavour does the preview support?
CommonMark plus GitHub Flavored Markdown (GFM) — tables, task-list checkboxes, strikethrough, and fenced code blocks with a language hint.
Does my Markdown ever leave my browser?
No. Parsing and rendering happen entirely in your browser using the marked library bundled with the page — no upload, no server, no network request of any kind.
Can I copy the rendered HTML?
Yes — click 'Copy HTML' to put the rendered HTML string on your clipboard. Click 'Copy Markdown' to copy the raw source instead.
Will links in the preview navigate away from the tool?
No. Every link in the rendered preview opens in a new tab so you stay on the tool.
How do I save my Markdown?
Click '⬇️ Download .md' to save the editor content as a .md file. Your browser handles the download — nothing is sent to a server.
