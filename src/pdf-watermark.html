FAQ

Do my PDFs ever leave my computer?
No. All processing happens locally in your browser using pdf-lib — no upload, no server, no third-party API.
How does text watermarking work?
Your text is rasterized to a transparent-background PNG via the browser Canvas API with your chosen font, size, color, opacity, and rotation. That PNG is then embedded into the PDF as an image overlay — no font subsetting required.
What page range syntax does the tool accept?
The same convention as PDF Splitter: comma-separated values — individual pages (5), ranges (1-3), or open-ended ranges (7- means page 7 through the last page). Leave the field blank to watermark every page.
Will the watermark affect the text in my PDF?
No. The watermark is an image layer drawn on top of each page. The underlying text, fonts, and content streams are untouched — the output PDF is still fully selectable and searchable.
What does Tile mode do?
Tile repeats the watermark in a grid across the full page. Density (Sparse / Normal / Dense) controls the gap between repetitions — Dense fills the page with tightly spaced copies, Sparse spreads them out.
