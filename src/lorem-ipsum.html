About Lorem Ipsum

Lorem ipsum is scrambled Latin filler — passages adapted from Cicero's De finibus bonorum et malorum (45 BC) and used by printers and designers since the 1500s. Because the letterforms are unfamiliar, the eye stays on layout, hierarchy, and rhythm instead of getting hooked on meaning.

How to use

  1. Pick a dictionary — classic Lorem or one of the flavored variants.
  2. Pick an output mode and how many of them you want.
  3. Tweak the options — classic intro and <p> wrapping.
  4. Click Shuffle for a fresh take, then Copy or Download.

Common use cases

  • Sanity-checking line-height, leading, and column width in a mockup.
  • Filling a CMS template before real copy is ready.
  • Demoing a component library or pattern with realistic-looking content.
  • Stress-testing truncation and overflow in cards, tooltips, and tables.

Tips

  • Toggle Start with classic intro off for fully random first sentences.
  • Use List items mode for menu, nav, or bullet-list mock copy.
  • Switch to Cupcake, Bacon, or Hipster if a client keeps reading the Latin.
  • Always replace placeholder text before shipping — it's nonsense.

FAQ

What does 'lorem ipsum' actually mean?
It's scrambled Latin adapted from Cicero's De finibus bonorum et malorum (45 BC), used as printer's filler since the 1500s. Designers reach for it because the unfamiliar letterforms keep the eye on layout instead of meaning.
Why are there alternative dictionaries (Cupcake, Bacon, Hipster)?
Same purpose, more fun. Cupcake leans dessert words, Bacon leans meat words, Hipster leans artisanal-coffee-shop nouns. Pick whichever fits the vibe of what you're mocking up.
Will the first paragraph always start with 'Lorem ipsum dolor sit amet…'?
Only when the dictionary is set to Lorem and the 'Start with classic intro' toggle is on (both are the default). Turn it off if you want a fully random first sentence.
Can I paste this into production copy?
No — it's nonsense Latin (or nonsense English). Treat it as a layout-only placeholder; replace it with real copy before shipping.
Does my generated text ever leave my computer?
No. The page is a single static HTML file; all generation happens locally in your browser with no network requests.
