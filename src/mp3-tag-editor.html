FAQ

Does my MP3 ever leave my browser?
No. Reading uses jsmediatags, writing uses browser-id3-writer — both pure-JS libraries bundled with the page. Your file stays in your tab and never touches a server.
Which ID3 version does the tool write?
ID3v2.3 — the most compatible target across players (iTunes/Music, Windows Media Player, Android, Sonos, in-car head units). The tool can read v1, v2.2, v2.3, and v2.4 but always writes v2.3 on save.
Will editing tags affect the audio?
No. Only the metadata header is rewritten; the MPEG audio frames are copied through byte-for-byte. The output is bit-identical at the audio level.
What happens to my album art if I only edit the title?
It's preserved. The tool captures the original APIC frame at load time and re-attaches it on save unless you explicitly click Replace or Remove.
How does Suggested from filename decide what's the artist and what's the title?
It splits the filename on " - " (dash with spaces) — the half before the dash becomes Artist, the half after becomes Title. Leading track numbers like 01 - or 03. are stripped first. Underscore-separated filenames split on the middle underscore and are flagged as low-confidence so you can double-check. Existing tag values are never overwritten — suggestions only fill blanks.
