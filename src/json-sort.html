🔤 JSON Sort

Sort JSON object keys alphabetically, recursively, instantly in your browser.

About JSON Sort

Sort every key in a JSON object alphabetically — A→Z or Z→A — recursively through nested objects. Useful for canonicalizing config files, producing line-stable diffs, or comparing objects whose keys arrived in a different order.

How to use

  1. Paste your JSON into the input.
  2. Choose the sort direction (A→Z or Z→A).
  3. Copy the canonicalized output to your clipboard.

Common use cases

  • Making git diffs of JSON config files line-stable.
  • Canonicalizing a file before checking it into version control.
  • Comparing two objects that have the same keys in different orders.
  • Producing a stable fingerprint of a JSON value.

Tips

  • Arrays keep their original order — only object keys are sorted.
  • Sorting is recursive, so the entire tree is canonicalized in one pass.
  • The output is strict JSON; trailing commas or comments in the input are dropped.
