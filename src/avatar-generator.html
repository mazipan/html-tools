FAQ

How are initials extracted from the name?
The tool takes the first letter of the first word and the first letter of the last word (uppercased), giving you up to 2 characters. You can override them in the Initials field.
How is the avatar color chosen automatically?
A simple hash of the name string deterministically picks one of 8 preset colors, so the same name always produces the same color — no random flickering on reload.
Does the image ever leave my browser?
No. All rendering happens on a <canvas> element in your browser. Nothing is uploaded. The PNG download and clipboard copy are both generated locally.
What's the difference between Gradient, Flat, and Outlined styles?
Gradient fills the background with a two-tone linear gradient. Flat uses a solid fill. Outlined leaves the background transparent and draws a border plus initials in the chosen color.
Why does clipboard copy sometimes fail?
Clipboard access requires a secure context (HTTPS or localhost) and a user gesture. If it fails, use the Download button instead — the PNG is identical.
