FAQ

Do my PDFs ever leave my computer?
No. All processing happens locally in your browser using pdf-lib — no upload, no server, no third-party API.
Does rotating a page affect the text?
No. Rotation is applied through pdf-lib's page.setRotation() API, which writes a rotation angle into the page dictionary. Text, fonts, and annotations are untouched — the output stays searchable and selectable in any PDF viewer.
How many undo levels are supported?
Up to 50 operations. After 50, the oldest entry is dropped to keep memory use bounded.
Can I reorder pages on a touch device?
HTML5 drag-and-drop is unreliable on mobile touch screens. Use the ↑ Up and ↓ Down arrow buttons on each page card to reorder pages on mobile.
What does Reset do?
It restores the grid to the original page order and original rotations from the source PDF, and clears the undo and redo stacks.
